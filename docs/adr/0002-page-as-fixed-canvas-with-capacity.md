# 页面为固定画布、带容量上限

页面(Page)是走马灯中的一屏,且是**固定画布**:内容必须在视口内完整呈现,不产生纵向滚动条。滚轮事件用于在页面之间切换,而非在页面内滚动。桌面端为 6 列网格,行数由视口高度决定(典型 4 行)。

由此推导出容量约束:一页可容纳的格子总数(列数 × 行数)有限。当图标占用格子之和(小=1, 中=4, 大=6)达到容量时,该页拒绝再新增/拖入图标,提示用户新建页面或移至其它页。编辑模式下页角标显示剩余格数。

这是用"无滚动 + 固定信息密度"换取"无限容量"的刻意取舍。备选方案——自动缩放密度(图标越多越挤)或允许横向滚动——前者破坏尺寸=信息密度的承诺(Q3=C),后者重新引入滚动条,均与"固定画布"语义冲突。容量约束是无滚动模型的必然结果。
