# 待核验线索 seam 加宽:部分认领残余 ID 与 AA 同名未映射,线索不再只认「整条未认领」

背景:架构审查(2026-09-01,准确性透镜)发现历史三次准确性事故(GLM-Image 误链、K2.7 臆造、评测伪动态)全是**全量失败**路径的 bug——已修、各有回归锁;而现存盲区全在**部分失败**路径:OpenAI 一条 changelog 混排「已入基线 + 未入基线」两个 `Model:` ID,认领一半后另一半不可见;通义一格多 ID 混排同理;AA 每日全表在手,`matchEntries` 的 `if (m === undefined) continue` 让漏映射静默留空。三条防线(零条目判改版、线索机制、stale 标记)恰好都只覆盖全量失败。原线索 interface `clue: PendingClue | null` 单数形态本身堵着多信号:一条条目产多条线索无处安放。

**决策一(interface):`clue` → `clues: PendingClue[]`。** 命中可多条、线索亦可多条——语义对称。七家返回处机械迁移;智谱/Anthropic/xAI/DeepSeek 四家的整条线索行为不变(描述文本无结构化 ID 可拆)。

**决策二(残余 ID):OpenAI 与通义两家,未认领 ID 一条一裸键——全未认领与部分认领同构。** 两家有官方结构化 ID(OpenAI `Model:` 字段、通义表格 ID 列),残余计算零猜测。原设「全未认领保持整条键、部分认领走裸键」双形态,review 修正后统一裸键(OpenAI 原 `${date}|${ids}` 整条键退役):双键并存会让同一模型在基线收录部分成员后、旧整条行 7 天滚出前的过渡期双行同现。`-latest` 后缀的移动别名不落残余(CONTEXT:「latest 只是引用方式,不另算模型」;changelog 里 `gpt-5.3-chat-latest` 与 `gpt-5.3` 同条是常态)。通义格内第三方托管 ID(kimi-k3 等)照落——title「ID:说明」标明观察位置。

**决策三(AA 同名未映射):三层口径,窄而零猜测,只在 LLM 主表收集。** AA 条目同时满足:①slug 圆点归一(小写+`.`→`-`)后与**同厂家基线行**(officialId/matchAliases)精确相等;②不在 `AA_MODEL_MAP`;③`model_creator.slug` 映射出的厂家与基线行一致——creator **已知且指向别家**才拦(防跨家撞名),未知值放行:同名本身即归属证据,未知值跳过会让 creator slug 漂移(旧口径 'zhipu')静默失能整个信号(review 修正)。LLM 端点 creator 值 2026-09-01 实测:智谱='zai'、月暗='kimi'。→ 落该厂家线索,键=`aa:<slug>`(与残余 ID 裸键不撞)。线索归属厂家(落在对应厂家 tab 的折叠区),不扩 `ModelProviderId` 枚举——加 'aa' 会强制 `Record<ModelProviderId, ProviderDef>` 挂 AA 的 ProviderDef,违反 ADR-0038 §6「评测源不纳入」。**媒体端点不收集**(review 修正):媒体无 model_creator(交叉校验缺席)且 slug 带厂商前缀+下划线形态(`openai-gpt_image_1-5`),与基线 id 归一永不相等——收集形同死代码还引裸同名误配风险。

**拒绝项:slug 前缀枚举口径(量级实测否决)。** 原设「前缀匹配×未映射」过滤,线上实测 624 条中 7 家 310、未映射 216、排除常见变体后缀后仍 106 条——旧模型页(claude-2/gpt-4.5/qwen2.5 系)与变体形态淹没每月一两条的真信号(ADR-0050「预发布稀释红点」同款教训)。同名口径把量级收窄到 2026-09-01 实测 23 条**真·映射缺口**(该配没配,人工补映射后自愈;python 盘点初版报 25 系映射表无引号键 `o1:`/`o3:` 被正则漏计,真实实现在正确映射判断下为 23),「AA 收录了基线完全没有的新模型」不在此信号内——那由厂家信源的残余 ID 线索覆盖。同理拒绝:忽略/确认状态字段(存量 23 条消化即静默,个位数常态不配状态机,出现长期霸榜实例再按实例加)、xAI/DeepSeek 家族条目标题切分(自然语言标题无结构化 ID,切分是启发式——凿开「确定性解析」底线;这两家盲区由家族成员后续单独成条时的整条线索兜底)。

**首轮不静默**:评测首配静默(f0d6a32)保护的是事实链(动态);线索是给人看的待办,首轮全量暴露存量缺口正是价值。

**代价与取舍。** 换来:部分失败从「唯一发现方式是人眼比对线上页面」变「折叠区一行待办」;残余 ID 与 AA 缺口共用既有 ingestClues 全套(30 天窗/upsert/7 天读窗/收录自愈),零新表零前端改动。付出:`MatchEntryResult` 迁移触全部七家与既有断言(机械,106+14 用例全绿佐证);AA 同名判定把基线行当判据——基线收录新模型当天若映射忘补,次日轮询即出线索(正是设计意图),若 AA 尚无该模型页则无线索(漏检后果安全,与既有 slug 精确匹配口径一致)。
