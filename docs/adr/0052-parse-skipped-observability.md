# 解析层意外跳过可观察:parse 的 interface 携带 skipped,部分失败从结构性不可检测变一条告警

背景:架构审查(2026-09-01,候选 2)发现七家 provider 的 parse 各有静默 `continue`——上游改一半格式(日期形态变、数据行错列)时条目蒸发,无事件、无线索、无告警;改版判定只认「零条目」这一全量信号,与 ADR-0051 同属「部分失败」盲区。grilling 中两个事实修正重塑了设计:①报告列举的五处 continue 性质并不相同——**页面正常构成**(表头行、非 bullet 行、同 URL 重复卡,每轮恒定出现)与**防御性丢弃**(畸形日期、错列,实抓口径下应为 0)混计会把 skipped 变成常态噪音,「突增」信号被淹没;②报告举的头号例子(OpenAI 新增 Removal 类型词)实为覆盖缺口——类型行白名单是正向匹配、无 else 分支,白名单外新词被当正文吞进上一条目,检测它需要「猜哪行像类型行」,与 ADR-0025「不猜」立法相抵。

**决策一(interface):`parse` 返回 `E[]` → `{ entries: E[]; skipped: string[] }`。** 观测量进 interface 才进测试面;轮询层单点 `console.warn`(非空才说,对齐 changelog 既有「只在异常说话」风格),先于零条目判改版——全灭场景的 skipped 片段就是「上游变成了什么」的排障线索。片段为原始原文截 80 字符(`def.clipFragment` 单点):排障须对回上游原页,归一文本会丢肉眼可辨的形态线索。月暗一家例外用已提取字段合成(标题+日期):卡片窗口前 80 字符是头图标签,原始截断看不到排障关键——其余六家跳过点都在块/行开头,原始片段成立。

**决策二(口径立法):「意外跳过」与「结构排除」二分。** 意外跳过=实抓口径之外的形态(计入,空数组是全网常态基线,非空即真信号,无需阈值/状态/趋势记忆);结构排除=页面正常构成(不计,计入则恒定噪音磨掉告警通道信誉)。逐家分类:通义(错列/日期校验失败/空模型格计入,表头 `<th>` 行不计;`cells.length===0` 与 `0<cells.length<4` 分开——前者纯表头,后者必为错列)、智谱(块日期 label 畸形)、Anthropic(`###` 段非日期形态)、OpenAI(类型行遇空日期上下文)、DeepSeek(`Date:` 回滚失败与 h3 标题剥空计入,无 `Date:` 前缀段不计)、月暗(日期回滚失败计入——**顺手新增防御**,原正则 `/20\d{2}-\d{2}-\d{2}/` 无回滚校验,`2026-13-45` 会直接产出非法日期条目;非 card-title 窗口/无日期卡/同 URL 重复不计)、xAI(**零意外跳过点**——段级丢弃均为设计性,月份标题形态变化要么整段灭走零条目通道,要么无猜判据缺失)。分类表由每家 ≥1 条畸形用例钉死:谁改口径谁先红。

**决策三(OpenAI 新类型词缺口:接受,不补)。** 白名单外新类型词(如 Removal)在无猜约束下结构性不可检测;缓解=OpenAI changelog 为追加式页面,entries 骤降人工可察觉。拒绝启发式小猜(行首大写词+分隔符形态):误报会制造假警报,比漏检更磨告警通道信誉——准确性透镜的主敌是臆造信号。

**决策四(月暗 fixture 换实抓快照)。** 原 `card()` 按 08-25 实抓口径**合成** HTML——合成者参照解析器期望形态生成,与「标的检索 fixture 假绿」事故同型,上游漂移不失败、七家中漂移风险最高。本票改签名窗口期顺手换成 2026-09-01 实抓节选(两页完整卡片区:资讯 5 卡、Blog 20 卡含真实同 URL 头图/列表重复卡)。`card()` 保留仅供畸形注入用例。

**实抓快照即刻兑现的收益:暴露一个真实线上缺陷。** 上游 HF 用户名大小写已漂移(`MoonshotAI`→`moonshotai`),基线占键 URL 与解析器产出 URL 逐字节不等 → 去重键失效 → kimi-k2 同公告(2025-09-05)双行,**合成 fixture 永远不会暴露**。本票不越界修(动基线数据/键归一是候选 3「去重协议代码化」的范围),测试如实断言 4 条并注释记档——那是下一票的活案例。

**拒绝项。** 散点内部 warn(37 处测试直调零改动,但观测逻辑散七家、测试要 mock console,locality 差);落库趋势表 provider/ts/entries/skipped(能判突增但零新表优势没了,趋势价值已被决策三否决——追加式页面骤降靠人工);每轮无条件 info 日志(与「只在异常说话」风格相悖);skipped 落待核验线索表(跳过项无结构化归属与日期,构造不出 PendingClue,只走日志)。

**评审修正(code-review 15 findings,13 收编 2 记档)。** ①OpenAI 日标题原只查 1–31 范围,任意三字母词+数字(`### Foo 5`)沿用旧月份静默错记——补**月份缩写词表**(实抓口径日标题是「月缩写 日」`### Aug 21`;评审与初版实现都先猜错为星期缩写,fixture 是词表唯一权威)+ **按月回滚**(`### Sep 31` 拒),畸形清空上下文走意外跳过;候选 1 时期写的 `### Sat 30` 合成 fixture 同步修正。②xAI 元旦窗口:无年份月份标题按 currentYear 取年,1 月看上年旧段全错记新年份,产未来日期事件且去重键永不同、双行不愈——无年份月份 > 当前月时归上一年(12 月底挂次年 1 月无年份的边界仍错,上游显式带年份可能性高,接受)。③xAI 带四位年份但月份词不识的标题(`## Sept 2026` 缩写漂移)原整段静默丢——年份后缀是无猜的「这是月份标题」结构证据,落意外跳过(与 Anthropic 同构场景口径一致)。④智谱双 lookahead 匹配不到的块(属性缺失/改名)原三通道全盲(无 entry 无 skipped 无零条目)——补开标签对账,不可见块落意外跳过。⑤DeepSeek 未补零日期(`Date: 2026-9-1`)原整段吞进结构排除——智谱/百炼上游实测产未补零,同源漂移不该在此蒸发,归一接受;回滚校验统一走 def.isRealIsoDate(月暗共用,防第三种私有形态增殖)。⑥片段形态三家修正:通义原始 tr 截断在 live 页会吃掉日期格(首格含 help-letter-space span)→ 归一 cells 拼接;智谱原始块截断会被前置长 description 推走畸形 label → 合成「label description」;月暗合成片段日期前置防长标题截尾。⑦clipFragment 按码点切,防代理对拦腰截断产孤立代理项。⑧warn 日志只打前 5 条片段(一个畸形月标题可让百余条类型行全落 skipped,全量打冲刷日志通道),数组保持全量供测试。⑨「skipped 空是全网常态基线」不变量补守卫测试钉七家(OpenAI 例外注明:主 fixture 特意混畸形段)。⑩warn 集成用例改显式 await pollProvider(init 内轮询不被等待,靠 archive 微任务预算排干是时序耦合)。记档不修:kimi-k2 HF 大小写双行(候选 3 根治,测试如实断言 4 条);kimi-k3 2026-08-28 营销文《法律行业为什么都在用 Kimi K3?》被标题 alias 归属为 updated——营销文鉴别特征属启发式猜测不立法,待归属规则票。

**代价与取舍。** 换来:结构破坏型部分失败从「人眼比对线上页面」变「容器日志一行带片段的告警」;口径分类表进测试面。付出:`ProviderDef.parse` 签名迁移触七家与测试 42 处直调(机械,115 用例全绿佐证);「实抓口径之外」的判据由人肉维护——上游正常演进新增无害形态会误报,但 warn 带片段可一眼判明,多报方向安全。
