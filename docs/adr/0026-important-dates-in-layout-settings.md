# 重要日子寄放布局设置,不另立账号级数据表

「倒计时」(CONTEXT.md)需要持久化用户配置的「重要日子」列表。可选两条通道:布局设置 blob(`layout_settings` 表)寄放一列 JSON,或照「博主」范式(ADR-0023)另立账号级表 + CRUD API。选前者:「默认搜索引擎」已有寄放先例,列表量小(个人几十条内),整份 LWW 同步语义完全够用;关键差别在**备份/恢复**——config blob 随导出 JSON 与双端镜像免费走全链路,独立表则要单独迁移与备份纳入,工作量数倍而概念收益近零。代价是「纪念日不是布局」的概念瑕疵,以 CONTEXT.md「重要日子」词条正名 + 本 ADR 备查来偿付。将来若列表膨胀出结构化查询需求(搜索/分组/跨年视图),迁独立表的路径是单列 JSON → 新表一次性搬运,可逆。
