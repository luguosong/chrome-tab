# 01: 贯通智谱文本模型的「模型追踪」首片

**What to build:** 让用户能添加一个全局单例的 3×2「模型追踪」图标,并通过一个经核验的智谱文本模型看到从全局模型档案、持久保留、刷新状态到图标和详情展示的完整路径。同时记录「厂家专属解析 + 全局持久档案」的架构决策。

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] 「模型追踪」可从新增入口添加,全局最多一个实例,图标固定占 3×2 格。
- [x] 图标滚动列表显示至少一个经官方信源核验的智谱文本模型,含厂家、模型种类、发布阶段、开放方式与最近动态。
- [x] 标头「更多」打开详情 Modal,可在「全部」与「智谱」 tab 中展开模型行,查看基本资料、动态和原始信源。
- [x] 24 小时内的新动态显示时间驱动红点,无已读状态。
- [x] 模型档案对所有用户共享、服务重启后仍存在;信源失败保留最后成功结果并标记陈旧。
- [x] 架构决策文档说明为何使用厂家专属确定性解析与全局持久档案,以及为何不开放任意厂家/信源配置。
- [x] 最小自动检查覆盖单例/占格、档案持久化、基本去重、陈旧降级与前端渲染。
