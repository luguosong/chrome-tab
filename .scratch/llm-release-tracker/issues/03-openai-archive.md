# 03: 接入 OpenAI 模型档案

**What to build:** 让用户在「模型追踪」中查看 OpenAI 官方发布的各类 AI 模型、历史、当前资料与动态,同时避免别名和快照造成重复。

**Blocked by:** 02: 补齐智谱全类型模型档案.

**Status:** ready-for-agent

- [ ] OpenAI 官方目录与发布记录中可证实的文本/理解、图像、视频、音频/语音、向量、审核/分类及开放权重模型进入档案。
- [ ] 产品发布、API 上线、权重开放、阶段、价格、能力、限额、弃用与退役等官方动态按事件分别保留。
- [ ] GPT 的独立命名型号/变体各算一个跟踪模型;移动别名、`latest` 与日期快照不另占一行。
- [ ] OpenAI 出现在图标、「全部」 tab 与独立 OpenAI tab;行展开后能查看资料、来源与时间线。
- [ ] OpenAI 信源失败只标记该厂家陈旧,不清空档案或影响其他厂家。
- [ ] 自动检查覆盖官方条目解析、型号/别名/快照去重、多阶段动态、厂家降级与前端 tab 展示。
