# 02: 补齐智谱全类型模型档案

**What to build:** 让用户在已可用的「模型追踪」中看到智谱八类 AI 模型、官方可证实的历史与完整资料,并将这条完整厂家路径作为后续厂家接入的稳定范式。

**Blocked by:** 01: 贯通智谱文本模型的「模型追踪」首片.

**Status:** ready-for-agent

- [ ] 智谱官方可证实的文本、多模态理解、图像生成、视频生成、音频/语音、向量、重排、审核/分类模型都进入档案。
- [ ] 历史基线只包含官方一手来源可证实的模型与动态;智谱平台托管的第三方模型不被归为智谱自研。
- [ ] 独立命名变体分别显示,移动别名与日期快照不制造重复模型。
- [ ] 详情可展示官方价格、上下文与其他限额、官方披露的训练参数量、开放方式、发布阶段、完整信源与动态时间线。
- [ ] 价格保留官方币种/单位/地区/生效日,限额保留套餐与地区作用域;未官方披露的参数量显示未知。
- [ ] 已退役模型保留、标记并排在可用模型之后。
- [ ] 自动检查覆盖八类映射、厂家归属、历史去重、多事件保留、退役排序与详情缺省值。
