# 票 11 服务器 ETL 演练留档(2026-08-22,切换日对照用)

环境:chrome-tab-backend:latest(Node 版,含 dist/etl.cjs)一次性容器,
chrome-tab_default 网络内以服务别名 mysql 直连线上 MySQL;凭据 --env-file /opt/chrome-tab/.env;
全程只读(SELECT 7 表),线上三容器 uptime 连续、公网 200/401 不变。

命令(切换日重跑即此行,目标路径换成正式 data/newtab.db):
  docker run --rm --network chrome-tab_default --env-file /opt/chrome-tab/.env \
    -e MYSQL_HOST=mysql -v /opt/chrome-tab/etl-rehearsal:/out \
    chrome-tab-backend:latest node dist/etl.cjs /out/newtab-rehearsal.db

四个未知数清零:
- 网络:容器经 chrome-tab_default 直连 mysql:3306,无跨主机问题
- 权限:DB_USER 对 7 表 SELECT 足够
- 数据规模:25 行 + changelog_snapshot ~498KB LONGTEXT,0.4s
- 字符集:utf8mb4,对账全行逐字段严格相等(含中文)
