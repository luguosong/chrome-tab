# Spec: 倒计时(时钟 hover 弹层的日期临近视图)

Status: ready-for-agent
Created: 2026-08-25
Sources: /grill-with-docs 会话定案(11 问全决,用户按推荐拍板);领域词条已入 CONTEXT.md(「倒计时」「节假日」「重要日子」)。

## Problem Statement

用户希望在左上角时钟的 hover 弹层里看到临近日期的天数倒计时。日期有两路来源:

1. **节假日**(内置,自动计算,不可配置):中外节日固定清单 21 项——中国法定 7(元旦/春节/清明/劳动/端午/中秋/国庆)、中国传统 5(除夕/元宵/七夕/重阳/腊八)、国际/西方固定 5(情人节/妇女节/儿童节/万圣节/圣诞)、西方浮动 4(母亲节/父亲节/感恩节/复活节)。农历节日经 lunar-typescript 换算当年公历;清明按节气日推定;除夕 = 春节前一日;浮动节日按规则计算。代码即配置(同「外源」内置枚举模式),每年自动推算。
2. **重要日子**(用户配置):每条 = 名称 + 日期(公历或农历,农历按当年对应公历推算、已过滚次年)+ 重复方式(每年循环 / 仅一次)。一次性条目过期后不再出现。

## 决策摘要(grilling 定案)

- **落点**:时钟 hover 弹层新分区(弹层最顶部,实用信息先于命理趣味信息),窗口内无数据时列表隐藏、保留编辑入口一行(纯隐藏会让第一条无处可加,grilling 共识微调)。不是图标类型,随时钟显隐(与「农历宜忌」姊妹)。
- **窗口与措辞**:距今 ≤30 天进入窗口;按剩余天数升序混排一列(节假日与重要日子不分家);当天显「今天」、次日显「明天」、其余显「N 天」。
- **存储**:重要日子寄放「布局设置」(`layout_settings` 单列 JSON,ADR-0026;同「默认搜索引擎」寄放先例),同步/镜像/备份/离线和解全链路随 config blob 免费获得。
- **编辑入口**:hover 弹层倒计时分区尾部「编辑」按钮 → 小 Modal(列表 CRUD);表单 = 名称 + 历法(公历/农历)+ 日期 + 重复(每年/仅一次);删除带 ConfirmButton 二次确认(项目惯例)。
- **保存通道**:复用 `PUT /api/layout-settings`(useUpdateLayoutSettings),整份布局设置回写。

## 范围外

- 节假日清单不可配置(不提供开关/增删)。
- 无通知/提醒动作、无任意日期查询(不是日历)。
- 一次性条目过期后不显示「已过 N 天」。
